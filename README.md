# AI Resume Builder

This is a web application that uses AI to generate a professional resume based on user input. It includes features for monetization, such as a paywall for PDF downloads and premium templates.

## How to Run Locally

1.  Clone the repository:
    ```
    git clone https://github.com/your-username/ai-resume-builder.git
    ```
2.  Install the dependencies:
    ```
    pip install -r requirements.txt
    ```
3.  Run the application:
    ```
    python app.py
    ```
4.  Open your browser and go to `http://127.0.0.1:5000`.

## Monetization Features

*   **PDF Download:** The resume is initially displayed as a watermarked preview. To download the resume as a PDF, the user must make a payment through PayPal.
*   **Template Upsell:** The application offers a selection of resume templates. The "Classic" template is free, while the "Modern" and "Creative" templates are premium and require payment.
